RAZEM — STRONA HTML

W tym folderze znajduje się index.html. Cały wygląd CSS i kod JavaScript są umieszczone w tym jednym pliku.

JAK SPRAWDZIĆ LOKALNIE
1. Otwórz index.html dwuklikiem w przeglądarce.
2. Wpisz nick i wiadomość, a następnie kliknij Wyślij.

WAŻNE
To statyczna demonstracja interfejsu czatu. Wiadomości są dodawane tylko do aktualnie otwartej strony w danej przeglądarce. Nie są przesyłane do innych komputerów i znikają po odświeżeniu strony.
Aby użytkownicy mogli rzeczywiście rozmawiać między komputerami, potrzebny jest backend/serwer czatu (np. Node.js + Socket.IO) lub zewnętrzna usługa realtime.

JAK OPUBLIKOWAĆ NA RENDER
1. Utwórz repozytorium na https://github.com/new
2. Wgraj index.html (ten plik README jest opcjonalny).
3. Na https://render.com/ wybierz New -> Static Site.
4. Połącz GitHub i wybierz repozytorium.
5. Build Command pozostaw puste.
6. Publish Directory ustaw na pojedynczą kropkę: .
7. Utwórz Static Site i poczekaj na wdrożenie.
8. Otwórz adres .onrender.com podany przez Render.
